# 🤖 Agentic-AI

A curated collection of **Agentic AI applications, LLM-powered systems, and AI experiments** built using **ChatGPT-assisted development**, modern AI frameworks, and real-world problem-solving approaches.

This repository focuses on **learning by building** — exploring how **LLMs, AI agents, RAG systems, and automation** work in practice.

---

## ✨ Why Agentic-AI?

- 🧠 Learn **Agentic AI concepts** by building real projects
- 🤖 Explore **LLM-based agents**, tools, and workflows
- 🔍 Understand **RAG, reasoning, memory, and orchestration**
- 🛠️ Hands-on implementations, not just theory
- 🚀 Built step-by-step with the help of **ChatGPT**

---

## 🧩 What This Repo Contains

### 🤖 AI Agents
- Task-based intelligent agents
- Tool-using and reasoning agents
- Multi-step decision-making agents

### 📀 RAG (Retrieval Augmented Generation)
- Document-based question answering
- Local + cloud RAG pipelines
- Embeddings, vector search, and context injection

### 🧠 LLM Experiments
- Prompt engineering experiments
- Reasoning and chain-of-thought style workflows
- Model behavior testing

### 🧪 Mini Projects & Demos
- Streamlit-based AI apps
- End-to-end AI workflows
- Proof-of-concept implementations

---

## 🏗️ Tech Stack

- 🧠 **LLMs**: OpenAI / Gemini / Open-source models
- 🐍 **Python**
- ⚡ **Streamlit**
- 🔗 **LangChain / Agent frameworks (where applicable)**
- 🗂️ **Vector Databases (FAISS / Chroma – planned)**
- 🛠️ **APIs & Tools**

## 🚀 Getting Started

```bash
git clone https://github.com/Aniket-Chinchankar/Agentic-AI.git
cd Agentic-AI
````

Install dependencies (project-specific):

```bash
pip install -r requirements.txt
```

Run apps (example):

```bash
streamlit run app.py
```
